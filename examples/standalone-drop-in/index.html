No build step at all

This page has no package.json, no bundler, not even <script type="module">. It's one prebuilt file — dist-standalone/aeon.global.js (~3.7 kB gzipped for core + router + forms + DI combined, ~2.2 kB for core alone) — loaded the way you'd load jQuery in 2012. Rebuild it any time with node scripts/build-standalone.mjs.
